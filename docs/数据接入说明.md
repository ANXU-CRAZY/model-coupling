# 真实数据接入与下一步

## 目前可以做什么

提供已经对齐的 MaxEnt/HQ 输出即可先运行固定对照；动态权重训练还需要独立监督与预测来源记录。郑州市试点已接入原始观鸟、60 个环境图层及历史 MaxEnt/HQ/威胁输出，生成了保护对照；真实重新训练和校准仍未执行，进度与缺项见 [郑州市试点实施路线](郑州市试点_实施路线.md)。

## 最小数据包

| 数据 | 用途 | 要求 |
|---|---|---|
| 四季 MaxEnt GeoTIFF | M | 写明物种/功能类群、训练时期、环境变量、背景范围、RM、FC、输出变换及预测来源 |
| `quality_c_ref.tif` 或每个情景 HQ | Q | 写明 InVEST 版本、threats/sensitivity、k、输入时间，不能把历史结果当新运行结果 |
| LULC 与 sensitivity.csv | H_j 查表 | 现状土地编码与 sensitivity 对应，生成 `habitat_suitability_by_lulc.tif` |
| threats.csv 与三类威胁栅格 | InVEST 校准 | 三类图层强度、距离尺度和敏感度要可解释，边界外威胁需要合理缓冲 |
| 参考栅格和研究区掩膜 | 空间统一 | 继承 100 m 接口，但使用真实 CRS；面积预算应使用合适的投影和面积计算方法 |
| 带年份/季节/样点/努力量的观测 | 底层训练与独立生态验证 | 记录观察时长、次数、设备/样线、检测条件；重复像元/站点先按设计聚合 |
| 可修复性/土地用途约束图层 | A | 现场与管理依据，不能仅由“低 HQ”自动生成；当前代码用明确的 0/1 掩膜 |
| 独立保护/修复目标与定义 | 门控监督 | 不能由 M、Q、旧综合 Score 或其阈值生成；允许某任务完全缺失 |

仅有原始出现点时，优先完成 MaxEnt 与空间分区、底层参数对照和独立生态调查，不先伪造修复监督。原来的 2025 秋/冬外部验证可以作为有限初步证据，但需新增适用于锁定评估的数据。

## CSV 字段

`templates/samples.csv` 为表头模板，真实行必须由数据产生，不能用演示数据替换。

| 字段 | 内容 |
|---|---|
| `sample_id` | 稳定、全局唯一的分析单元标识；训练/校准来源引用同一标识系统 |
| `site_id` | 站点或参考栅格像元 ID。重复观测先聚合，禁止分散在门控训练/验证中 |
| `group_id` | 依据空间相关性论证的空间块 ID；不是随意按行编号 |
| `year`,`season` | 时间；season 仅用 spring/summer/autumn/winter |
| `m`,`h` | 同物种/类群、同季节、同空间单元的 M 和 Q，均为 0–1；不能混用 raw/logistic/cloglog |
| `u_m`,`u_h` | 你们实际基模型成员的预测标准差，非负。没有成员时填 0 仅表示“未量化”，不表示完全无误差；正式元信息需明确这一点 |
| `feasible` | 修复适用/可行性 0/1，来自独立核查 |
| `habitat_suitability` | 该像元对应 InVEST sensitivity 表的 H_j；应与生成 HQ 的参数成员匹配 |
| `role` | train/validation/test，先定义并冻结；固定基线无需该列 |
| `m_artifact_id`,`h_artifact_id` | 对应 provenance.json 的基模型输出记录 |
| `target_protection` | 有独立来源且尺度定义明确的保护监督，0–1。未知用空值，不填 0 |
| `target_restoration` | 有独立来源的修复候选/效果监督，0–1。未知用空值，不用鸟出现代替 |

多物种可额外提供 `species_id`；当前特征尚未学习物种编码，第一版建议按单一物种或明确的功能类群分别运行。不同物种的生境需求不能无解释地平均后称为水鸟总体适宜度。

对只有汇总年度 HQ 的情况，四季共用同一 HQ 是静态质量底层加季节适宜性/权重；应如实描述。若要声称季节生境质量变化，应有实际时序威胁/LULC 输入，或有依据的季节参数模型，不能只复制 HQ 并改文件名。

## 参数表迁移

当前 InVEST 适配器要求 `threats.csv` 的 `max_dist` 用米、`sensitivity.csv` 的土地编码列为 `lucode`。历史配置表里的 1.5/1.0/2.5 km 对应 1500/1000/2500 m，仍只是历史情景值；权重 1.0/0.7/0.6 与 k=0.5 也需重新评估，不能因为历史使用过就视为最可信参数。

InVEST 3.15 的变化还包括计算和字段。要复现旧项目，先确认当时版本；要与新版本比较，完整保存模型版本并重跑基准，不能只替换数字后假定输出相同。

`invest_prior.pending.json` 故意留空本地参数范围。可以为 sensitivity 增加 `sensitivity:土地编码:威胁名`，为土地类型适宜性增加 `habitat:土地编码`。这些参数的个数应受可用独立样本和生态依据约束，先研究少量关键自由度。

## 分区与管理含义

参考分区编码：0=NoData，1=保护参考，2=修复候选参考，3=维持参考，4=一般治理参考，5=需核查/另建土地转换情景。它们依照冻结的 M/Q 阈值与可行性产生，与连续排序分开。

连续 C 与 R 可以同时较高，不能直接逐像元取大者强行划互斥区。当前参考象限解决的是解释分组；正式的地块选择还需保护目标、面积/成本、连通性、现有保护地和土地用途约束。v0.1 尚未实现最终预算优化、管理边界划定或实测修复收益估计。
