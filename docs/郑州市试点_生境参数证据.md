# 郑州市试点：水鸟生境参数证据与待校准项

更新日期：2026-10-01。目标接口：InVEST 3.16.1 Habitat Quality（HQ）。

当前结论：已整理历史方案和外部研究的参数证据，但本地地类编码映射、各类群的生境适宜性 `H_j` 和威胁敏感度仍未确定。现阶段配置是证据登记草稿，不能作为已审核先验运行正式 HQ，也不能将历史 HQ 称为已校准的郑州水鸟生境质量。

## 1. 参数各自代表什么

`H_j` 表示目标物种或类群对地类的相对适宜性；敏感度表示该地类生境对某一威胁的相对敏感性。二者通常均在 0–1 内。威胁权重表示不同压力的相对强度，最大距离与衰减方式描述其空间影响。HQ 是相对质量指标，不等于实测鸟类数量、占域率或修复收益。若要面向特定水鸟类群，适宜性、威胁和敏感度都须与这个对象对应。[InVEST 官方 HQ 文档](https://storage.googleapis.com/releases.naturalcapitalproject.org/invest-userguide/latest/en/habitat_quality.html)

本页将证据分为：项目历史设定、外地文献借用、当地调查估计和有记录的专家评定。目前未形成后两类的完整本地参数表。论文引用和数值登记不能代替本地校准。

## 2. 已找到的历史威胁方案

随输入材料提供的《5.1作品介绍》及《7.1地理处理自动化模型说明文档》明确描述了以下方案。这些文字作为来源记录使用，不构成已经测量或验证参数的证据。

| 图层名称 | 历史权重 | 最大距离：米 | 衰减 |
|---|---:|---:|---|
| `urban_structure`：城市结构 | 1.0 | 1500 | exponential：指数 |
| `human_activity`：人类活动 | 0.7 | 1000 | linear：线性 |
| `night_light`：夜间灯光 | 0.6 | 2500 | exponential：指数 |

历史半饱和常数 `k=0.5`。以上值属于**项目历史设定**，尚未找到支持其为郑州水鸟实测效应、专家评定结果或独立调查拟合结果的记录。

距离已由档案中的公里换算为米：InVEST 3.15 起 `max_dist` 从公里改为米，3.16.1 必须沿用米单位。[官方版本变更记录](https://github.com/natcap/invest/blob/main/HISTORY.rst)

## 3. 现有 LULC 编码仍缺少来源映射

栅格实际具有整数值 `1..9`，原始 NoData 为 `255`。材料列出九类名称：永久水体、季节性湿地、乔木、灌丛、草地、农田、裸地／泥滩、建设用地、其他陆地。**名称列表的顺序不能证明这些名称与数字编码一一对应。**

已完成的只读核查包括：

- 两份 LULC 导出 TIFF 无类别名称、栅格属性表（RAT）和色表。
- 原生 UDBX 的 LULC 描述、扩展信息及统计文本为空；类别域和附加信息表无编码映射，波段仅标为 `Band1`。
- 输入档案中五份 DOCX 的正文和表格没有明确的 code→名称表。
- 通过已安装的 SuperMap Java SDK，以只读连接打开两份工作空间副本，提取 36 张地图及 14 个布局。唯一 LULC 地图为普通影像图层，未启用分类颜色字典；布局的压缩文本经 SDK 解码后，仅有模板占位和 `high/low`，没有地类编码图例。工作空间修改标记为 false，副本读取后的 SHA256 与提取记录一致。

因此 `lucode=1..9` 的 `name` 仍为 `null`，状态为 `PENDING_SOURCE_CROSSWALK`。不按覆盖比例猜类别，也不从旧 HQ 的最大值逆推 `H_j`。下一步需找到原始重分类规则、导出参数 CSV 或分类来源记录；也可建立来源明确的新 LULC。

## 4. 可核查的外部数值参照

### 4.1 黄河三角洲迁徙鸻鹬类：九类生境参照

Duan 与 Yu（2022）在 InVEST 3.7.0 中模拟黄河三角洲鸻鹬类生境。其 Table 1（PDF 第 4 页）给出以下值；作者说明这些参数取自已有研究，而非在郑州拟合。[原研究及 Table 1](https://www.mdpi.com/2072-4292/14/24/6191)

| 原研究类别：中文说明 | 原类别英文 | `H_j` | 对城市威胁的敏感度 |
|---|---|---:|---:|
| 农田 | Farmland | 0.40 | 1.00 |
| 水库／池塘 | Reservoir/Pond | 0.25 | 0.41 |
| 底滩地：须核对原分类语义 | Bottomland | 0.18 | 1.00 |
| 潮间带滩涂 | Tidal flats | 1.00 | 0.80 |
| 河口水域 | Estuarine waters | 0.89 | 0.70 |
| 河口三角洲 | Estuarine delta | 1.00 | 0.75 |
| 盐田 | Saltpan | 0.70 | 0.31 |
| 海水养殖区 | Mariculture | 0.55 | 0.41 |
| 未利用地 | Unused | 0.19 | 0.90 |

同表城市威胁距离为 7.10 km、权重 0.90；道路为 0.50 km、0.71。其研究采用 `k=0.5`、`z=2.5`。这些数值仅供比较，不能直接填入本地参数表。

主要迁移限制是滨海环境、鸻鹬类对象和精细海岸地类与郑州内陆多类群不同。“永久水体”不能自动对应某一种水库或河口水域；“裸地／泥滩”也不能直接对应高适宜性的潮间带滩涂。该表没有当前 `human_activity` 和 `night_light` 所需的完整参数。

### 4.2 黄河三角洲一般生物多样性：五类生境参照

另一项黄河三角洲 HQ 研究的 Table 2 给出下表。研究面向一般生物多样性，参数主要参考手册与既有研究，不能视为水鸟专属实测赋值。[Frontiers 原研究及 Table 2](https://www.frontiersin.org/journals/ecology-and-evolution/articles/10.3389/fevo.2022.1075914/full)

| 类别：中文 | 原类别英文 | `H_j` | 对建设用地威胁的敏感度 |
|---|---|---:|---:|
| 森林 | Forest | 0.9 | 0.6 |
| 草地 | Grassland | 0.8 | 0.6 |
| 水库／池塘 | Reservoir pond | 0.9 | 0.5 |
| 河流 | River | 0.8 | 0.4 |
| 泥滩湿地 | Mudflat wetland | 1.0 | 0.7 |

其建设用地威胁距离 2 km、权重 0.6、线性衰减。同样是水库／池塘，这里 `H_j=0.9`，而鸻鹬类研究为 0.25。差别反映研究对象及赋值定义不同，不能取平均后声称得到本地参数。

## 5. 郑州应按水鸟类群审查生境

建议先审查游禽／潜水取食鸟类、鸻鹬类、鹭类三组，其他水鸟另行评估；科级归属不自动等于取食或繁殖类群。盐城野外调查研究显示，不同水鸟类群对生境类型、植被和距离因子的响应不同，支持按类群建立参数证据，但不提供郑州的 InVEST 数值。[王成等，2022](https://www.ere.ac.cn/article/doi/10.19741/j.issn.1673-4831.2021.0370)

| 现有语义类别 | 本地审查重点 |
|---|---|
| 永久水体 | 区分深水、浅水和岸带；游禽与涉禽需求不同 |
| 季节性湿地 | 水文持续性、水深、淹水时间与植被结构 |
| 乔木／灌丛 | 鹭类繁殖及栖息功能；不能作为全部水鸟的最优地类 |
| 草地／农田 | 草滩、旱地、水田和管理强度；不能一律排为非生境 |
| 裸地／泥滩 | 干裸地与可觅食泥滩须分开 |
| 建设用地／其他陆地 | 核对实际组成，记录非生境判断及例外 |

黄河银川段连续调查同样显示，各类湿地的水鸟群落及优势物种不同，微生境与管理条件应进入审查。[王琳等，2024](https://www.geores.com.cn/sdkx/EN/abstract/article/1672-5948/76280)

郑州城市湿地研究可支持建筑压力、生境异质性等方向性假设，但没有本地 InVEST 参数矩阵。该研究使用中国观鸟记录中心数据，与现有观鸟输入可能重叠，不能未经来源核对就作为独立监督。[曹雪倩等，2024](https://www.geores.com.cn/sdkx/CN/10.13248/j.cnki.wetlandsci.2024.06.015)

## 6. 三类城市威胁需检查重复计压

城市结构、人类活动和夜光可能共同反映城市化。三个栅格分别缩放到 0–1，不足以证明效应尺度可比；彼此相关时，叠加可能重复计入同一种压力。官方 HQ 按加性威胁处理，因此需核查图层构建方法、尺度和相关性，再安排去除单个威胁的对照。[官方 HQ 文档](https://storage.googleapis.com/releases.naturalcapitalproject.org/invest-userguide/latest/en/habitat_quality.html)

河南黄河自然保护区研究纳入夜光及交通压力，可作为候选威胁的地区参考；它不提供本模型的威胁敏感度和距离。其 Table 3 中夜光的 z 值与报告的 p 值也存在不一致，不据此换算参数。[河南黄河研究](https://www.mdpi.com/2073-445X/12/6/1250)

在编码和敏感度具备证据后，可开展以下探索方案：

1. 历史威胁方案作为复现参照；每次去除一个威胁，包含去夜光对照。
2. 每次只将一个威胁的距离或相对权重乘以 0.5、1、2。若原始权重超过接口上限，按同一比例缩放全部权重，保留相对关系；不能将所有权重同时倍乘当成新情景。
3. 相同景观的可比情景保持 `k` 和分辨率一致；改变 `k` 单独作为敏感性实验。
4. 若最大距离扩大到 5000 m，威胁输入及结果边缘解释至少相应考虑 5000 m 缓冲。

这些倍数是分析者提出的探索设计，**不是实测参数区间或统计置信区间**。评价应包括排序相关、优先区重叠及参数变化导致的结果差异，不能仅挑选最符合预期的一张图。

## 7. 参数校准与独立监督的边界

参数记录至少包含：地类代码和来源语义、类群、季节、参数值、来源 URL 和原表位置、证据类型、迁移理由、评定者记录及本地校准数据范围。后续可补充水深／水位、湿地水文、标准化调查、繁殖／栖息地点和有记录的专家评定。

作为融合输入的 `Q`，应先由明确生态先验或开发数据内的独立调查校准。不要先用全数据 MaxEnt 的 `M` 给 `H_j` 赋值，再声称 `M` 与 `Q` 是两项独立证据。已有武汉研究采用 MaxEnt 排名调整 HQ 适宜性，这可以作为另一个依赖方案参考；如采用，必须折内处理并明确报告 `M→Q` 的依赖。[相关原研究](https://www.mdpi.com/2071-1050/17/13/6078)

校准、调参和融合训练需有分开的样本用途及来源记录；测试样本不能用于选择 `H_j`、威胁敏感度、权重、距离或 `k`。真实鸟类记录或管理评价可以成为监督来源，模型输出的乘积、阈值、排名或人工补写值不能冒充独立观测。
