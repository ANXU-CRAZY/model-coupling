# 郑州市水鸟试点：数据核查与实施路线

更新日期：2026-09-30。按用户提供的“MaxEnt × InVEST × 双头动态门控”七步图组织。附件及压缩包中的说明作为研究来源读取，没有作为操作指令执行。

## 当前完成范围

原始观鸟数据已核查，四季环境变量已从超图 UDBX 只读导出，观鸟记录已提取环境值，并生成历史保护排序对照。用户确认 ND 经纬度为 **WGS84（EPSG:4326）**，并说明没有额外的 InVEST 参数表或修复记录。

**真实 MaxEnt 尚未重新拟合，InVEST 尚未重新运行/校准，真实门控尚未训练。** 本机完成的网络训练仍是明确标记的合成工程演示；下文历史基线使用档案模型输出。

### 1. 观鸟数据

优先使用 ND 两份郑州原始 Excel，共 128,751 行、2014–2024 年。标准化表、合并表和分块表存在重叠，不能再次相加。原始表保留精确日期、地点、数量和来源行；某些标准化表把零数量改为 1，本项目保留原始值。

按 Wetlands International 的水鸟科范围建立候选清单，翠鸟科和鹗科单列。范围依据见[国际水鸟普查说明](https://www.wetlands.org/tools/international-waterbird-census/)及[水鸟种群估计第五版](https://downloads.wpp.wetlands.org/WPE5.pdf)。科级初筛得到 32,065 条、137 个中文种名、141 个拉丁名称；其中 32,064 条正数量记录进入出现候选。物种及异名仍待审定，不能称为已经确认的 137 个独立物种。

| 季节 | 科范围原始候选记录 | 正数量且环境变量完整的记录 | 去重 100 m 出现像元 | 全鸟目标类群背景候选像元 |
|---|---:|---:|---:|---:|
| 春（3–5 月） | 11,756 | 11,752 | 416 | 589 |
| 夏（6–8 月） | 4,479 | 4,479 | 240 | 346 |
| 秋（9–11 月） | 5,081 | 5,060 | 245 | 337 |
| 冬（12–2 月） | 10,749 | 10,737 | 331 | 470 |

像元去重仅处理重复空间单元，邻近像元的统计相关性仍需分析。出现候选保留原始坐标，环境提取用其所在像元；SWD 坐标是分析像元中心，没有按 NDVI 把观测点移到更适宜的位置。12 月冬季的 `season_year` 归入下一年，原始日期仍保留。

同一像元多次观鸟不会自动变成多个独立出现单元。原始数量、物种数、调查次数也不会直接生成门控标签；调查事件、努力量和重复报告还需核查。目标类群背景来自同源的全部正数量鸟类记录，可以包含水鸟出现像元，**不是已确认的缺失点**，其采样代表性尚未确定。

朱雀 Excel、同名 CSV 和“数据1206”监测 CSV 保持各自来源。文件名年份与记录日期有不一致，来源独立性未核实，不能直接视为新测试集。

### 2. 环境与历史模型

成功导出春/夏/秋/冬 **14/17/15/14 个变量，共 60 个图层**。原生环境网格为 EPSG:32649、100 m、1362×824；同时导出历史 HQ、9 类 LULC 及城市结构/人类活动/夜间灯光威胁图层。

发现并处理的接口问题：

- 历史 `*MaxEnt.tif` 标记 EPSG:3857，数值坐标却与 UTM49N 网格相符，像元和原点也与原始 ASC 不同。本次采用原始四季 ASC，不继承这些 TIFF 的标签或数值变换。
- ASC 缺 CRS。只有在尺寸和仿射变换与原生环境网格完全一致时，显式允许推定 EPSG:32649；记录原始 CRS、参考文件 hash、源文件 hash，并拒绝冲突的已有 CRS。这仍需原生产者确认。
- HQ/威胁/LULC 的原生 EPSG:3857 网格真正重投影至环境网格：连续变量双线性，分类变量最近邻，保留 NoData。
- **四季日间 LST 数组完全相同，四季夜间 LST 数组也完全相同。** 用户已确认是有意复用，可作为静态参考温度特征；合成时期、单位和 QC 仍未核实，不能推断四季温度或年际变化。配对候选输入已生成，尚未比较真实性能，见[LST 与独立监督方案](郑州市试点_LST与独立监督方案.md)。
- 热点和 PCA 产品含不适合直接充当 0–1 适宜性或 HQ 的值域，且部分季节产品相同，未将它们作为独立监督。

目前资料足以进行历史基线和 MaxEnt 输入诊断。正式同期季节建模仍需查明各变量时间与筛选来源；当前没有盲目启动 GEE 下载。若无法恢复原始时序输入，再按确定的研究年份补齐缺失变量。

### 3. 已生成结果与证据

四季分别生成三个保护排序对照：`sqrt(M×Q)`、`0.5M+0.5Q`、`min(M,Q)`，共 12 个 GeoTIFF。四季共用同一静态 HQ；只在 M/HQ 有效域交集计算。结果为**历史探索性指数**，未证明保护成效或优先区边界。

新 CPU 环境独立读取 CSV/GeoTIFF，检查 hash、唯一 ID、网格、NoData、有效域与三种融合算术，数据一致性审计通过。春/秋/冬各 762,865 个有效像元，夏 762,853。未将该检查当作生态准确性验证。

本机合成演示完成：480 行、168 个训练 epoch、最佳 epoch 128、1,240 个有效演示像元。没有把这些指标写为郑州实测结果。

## 参考论文的使用范围

张靖靖等《基于水鸟季节性时空分布的郑州市湿地生境适宜性演变研究》主要提供四季群落 MaxEnt、候选变量和研究背景；本文没有实施 InVEST 或双头耦合，没有提供 H_j、敏感度及修复监督。摘要称 136 种，方法报告处理后 26,907 条记录，但未交代物种筛选名单；本项目没有强行匹配其数字。来源：[论文 DOI](https://doi.org/10.20103/j.stxb.202508282245)，本地 PDF 方法见物理页 3–6。

论文的随机 75%/25% 验证不替代本项目空间嵌套验证。其 NDVI 辅助点位重定位、开发区剔除和全文阈值应单独审查，不能预先把环境偏好写入本项目观测真值。

## 按七步图推进

| 图中阶段 | 本地状态 | 下一步及进入条件 |
|---|---|---|
| ① 时空数据与验证分组 | 原始核查、WGS84 确认、环境提取完成；最终分组未确定 | 审定物种/类群、调查事件、研究边界和变量时期。根据空间相关性选块和缓冲，检查每折占用，锁定测试集。5/10/20 km 块仅作诊断 |
| ② MaxEnt | SWD 出现/背景候选已生成；历史 M 可作对照 | 恢复未筛候选变量并折内筛选，或预先定义与观测标签独立的生态变量集。RM×FC 在内层空间折选择，再输出外折 M 与成员离散度 U_M |
| ③ InVEST HQ | 历史 Q/LULC/威胁可读；完整参数表缺失 | 建立有来源的新 H_j/敏感度/威胁参数先验，记录单位与软件版本；有独立数据才能做折内监督校准。无独立真值时仅称先验敏感性分析 |
| ④ 折外特征与来源审计 | 历史全样本输出明确不是 OOF | 每个输出保留 fit/tune/calibrate 样本和空间组、变量筛选与归一化来源。禁止借历史图生成新 OOF 记录；不确定性不能冒充零误差 |
| ⑤ 双头残差门控 | 工程接口可运行；真实目标缺失 | 独立保护/修复目标及其尺度定义到位才训练。只有保护监督时可训练保护头；缺失修复监督时修复头保持常数并标记未训练 |
| ⑥A 保护排序 | 历史三种固定对照已生成 | 新模型按冻结流程训练后，比较固定对照和动态 C；不把统计权重解释为生态因果贡献 |
| ⑥B 修复候选排序 | 未生成 | 同时需要与 Q 匹配的 H_j，以及独立调查/管理约束支持的可行性 A。低 HQ 不能自动当作可修复地块或实测修复收益 |
| ⑦ 独立测试与管理核查 | 尚无已锁定并证实独立的测试数据 | 最终模型和参数冻结后评估误差、排序、成员稳定性与现场证据；原历史 2025 验证已经被查看，不能再称未见测试 |

现有出现像元可以支撑明确标注的探索性群落拟合，当前数据问题使它不能作为正式七步训练成果。正式新拟合采用明确的 SWD 空间拆分，避免默认随机验证。Java [MaxEnt 官方主页](https://biodiversityinformatics.amnh.org/open_source/maxent/)列出 MIT 开源 3.4.4；[官方参数表](https://raw.githubusercontent.com/mrmaxent/Maxent/master/density/parameters.csv)提供 `testsamplesfile` 等接口。新流程拟用 cloglog 并记录版本/hash；群落混合和观测偏倚条件未满足时，不把输出解释为单一物种出现概率。

### 缺数据时的研究安排

先把**保护分支**作为近期成果：完成 MaxEnt 的空间验证设计、形成有证据的 HQ 先验和固定对照。保护头仍需要独立生态观测/管理评估的目标；若没有，保留固定融合并开展独立调查。

修复分支先建立调查表：地块 ID、日期、土地类型与权属/用途约束、威胁、拟采取措施、现场可行性依据，以及标准化努力量下的修复前后鸟类/生境指标。独立专家评分可以用于“候选排序”监督；只有适当对照与前后实测才能研究修复收益。当前未知目标用缺失值，未知 A/H_j 保持空值。

后续已形成[生境参数证据](郑州市试点_生境参数证据.md)与[独立监督实施方案](郑州市试点_LST与独立监督方案.md)：14 行文献参照、27 行本地参数待审表、18 个威胁敏感性设计、8,407 个调查事件候选及五页本地编辑工作表。地类编码与本地 H_j/敏感度未确定，没有生成真实标签或运行新的 HQ/门控。

## 本机运行与文件入口

项目代码仍在 `F:\model_coupling`。磁盘不足时将本任务创建的 CPU 环境及 UDBX 解压副本转存至 `D:\model_coupling_generated_20260930`；原始观鸟文件和用户原 ZIP 未改动。该 F 盘不支持目录 junction，本项目用显式运行入口访问 D 盘环境。

Windows 运行入口临时使用 rasterio 随包的 PROJ/GDAL 数据目录，解决机器上的 PostGIS PROJ 数据库冲突；退出时恢复进程环境变量。

```powershell
Set-Location F:\model_coupling
& scripts\zhengzhou\run_windows_cpu.ps1 -PythonArgs @('-m','wetland_coupling','--help')
```

核心依赖锁定在 `requirements/windows-cpu.txt`。新环境可用 Python 3.12 创建后安装该文件和 `pip install -e . --no-deps`；运行入口的 `-Python` 可指定其他位置。
