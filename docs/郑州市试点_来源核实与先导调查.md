### 响应定义与准入

- **现有数据**：继续支持原出现/背景模型及记录使用画像；不进行缺失物种补零、每分钟鸟数校正或独立标签自动生成。
- **新采集的主要响应**：在实际记录的调查范围内、完成目标水鸟清单后，一次访问的目标水鸟检出/未检出。范围、努力量、名录版本和原始证据必须齐全。
- **次要响应**：物种级检出、完整计数下记录数量和记录丰富度。数量未知保留未知；完整调查而没有水鸟才能保存真正的0。
- **估计目标**：条件于标准努力量的水鸟遭遇/使用指标；不解释为真实缺席、绝对丰度、内禀InVEST H_j或修复收益。
- **空间支撑**：调查范围多边形/轨迹独立于站位点；按范围汇总环境和类组成。不能将整个可见水面中的鸟数归入站位所在100m单一像元。
- **监督隔离**：明确新原始访问是否参与底模拟合、调参、HQ校准、融合训练或最终评价。同一记录不得兼任所评价模型的校准与验证；新年份或不同团队不自动满足独立性。

保护目标仍需提前约定与管理需求相符的指标。修复目标需要措施、可行性和效果资料，最好有对照与前后监测。新水鸟使用指标不自动成为两个管理目标。

## 3. 可执行的地表核查候选设计

已执行`prepare_field_pilot.py`，引用`field_pilot_preparation_002`。候选边界为已登记的市域转换结果，其基准仍待独立验准；这不构成法定界认证。

- 城市候选边界内冻结共同域752,014像元；LULC及人类活动有效采样框750,438像元，另外1,576个因缺测排除。
- 九个**数字代码**各按本类人类活动中位数分较低/较高层，包含并列值时两层面积不等；它不是可达性分类。
- 每个代码×压力层随机抽2个初选1km块、2个备用块，各块随机抽一个有效像元中心。随机种子20261002。
- 共36个初选点、36个备用点，本次实现恰落在72个不同1km块。相邻块、同地点跨季及同块内访问仍可能相关，不将72称为独立样本。
- 初选像元纳入概率为`2 / 本层候选块数 / 所在块本层像元数`。此概率仅用于原初设计；不擅自套用于启用的备用点、改站位或删去不可达点后的样本。
- 选点没有读取鸟类位置、M/Q或测试分数。候选坐标只是地表核查目标，可能位于水面；实际合法可达的观测站位另行核查、登记。
- 先记录不可达原因与地表证据，按已保存顺序启用备用点；不能因为没有鸟替换样点。若可达性改变目标总体，应重新登记抽样框及推断范围。

36点属于覆盖九类和压力梯度的**先导工作量**，不是功效确定的样本量，也不是补足某类30个出现点。模型拟合前再根据先导检测率、组内相关、目标最小效应、空间覆盖与成本模拟样本量。

## 4. 访问协议起点与检测敏感性

建议起点是同一实际调查范围20分钟静点搜索、每季3次、约7天内完成；这些是操作安排，尚不是郑州本地验证的最优时长、检测概率或闭合窗口。先导记录观察中断、天气、水位、视域及鸟群移动，评估后登记正式方案。

程序已计算假设独立、恒定单次检测概率p时的`1-(1-p)^K`。例如K=3，p=0.1/0.2/0.4/0.6对应至少一次检出的概率27.1%/48.8%/78.4%/93.6%。这是条件于单元被使用的**假设敏感性**，不是观测检测率或实验功效。它说明固定三次访问也不能保证充分检测。

如果迁徙水鸟在窗口内频繁进出，优先使用访问级使用/遭遇指标；只有在物种、窗口和调查单元的闭合及检测假设可支持时再考虑占域模型。不用丰富度/计数之和强行替代未被识别的H_j。
