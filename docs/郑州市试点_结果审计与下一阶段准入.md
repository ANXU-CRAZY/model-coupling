## 2. 已纠正的口径

1. **LST空间对照混入拟合背景差异。** 旧空间指标来自各方案分别选出的 primary `M_oof`；夏1折、秋2折、冬1折的拟合背景不同。现在从既有24个B1外折成员恢复真正同背景空间对照，未改变任何候选模型或primary OOF。
2. **秋季测试表的“背景”含义含混。** 不同的是拟合背景；测试出现点与B1参考评价背景仍相同。差值不能单独归因LST。测试批次仍只消费一次。
3. **遗漏资格回退需要报告。** 24个外折主模型中6个按冻结最低遗漏率规则回退，8个最终模型的完整开发集选择均满足资格。原约束和选择规则未改。
4. **收敛范围需要区分。** 3,456个内层候选中422个到达迭代上限；8个最终、72个外折背景成员及32个主选择对应的96个内层拟合均收敛。没有增加迭代或更改候选网格。
5. **测试读取声明需要精确。** 后处理不读单独测试指标文件、不使用测试指标；但run manifest内含历史测试摘要，不能声称从未载入任何测试数值。

## 5. 下一阶段顺序

1. 确认研究问题和管理AOI。原生共同有效域支持方法学审计，不能自动当行政或保护边界。
2. 恢复原分类图例/重分类规则；若不能恢复，用有年份和官方代码表的产品另建输入版本。水体深浅、泥滩与干裸地仍需当地补充证据，不能凭覆盖代理猜代码。
3. 按已登记功能群审阅H_j、敏感度及威胁，核实来源缓冲。参数由可追溯文献/现场证据支持；独立校准仅使用底模训练范围内的开发资料。
4. 核查完整清单、努力量、调查单元与重复，定义真实观测响应；保护盲评与修复地块×措施可行性分开。模型输出不生成独立标签。
5. 证据准入后运行官方HQ，生成有来源的Q/U_Q；底模与监督均合格后，才启动门控和固定对照。原请求暂缓正式参数定权/真实门控的限制仍保留。

目前尚不能进入InVEST**正式校准**。最先需要可信LULC编码对应与当地生境参数证据；即使输入可执行，缺独立校准目标也不能把探索性参数扫描称为正式校准。
