## 3. 剖面方法需要保留的边界

旧方法是 `presence/background → 连续变量分类器 → 类内平均sigmoid → 除以最大类均值`。它混合了采样机制、当前环境和人为背景比例；最大值归一化不能消除sigmoid截距对数值的影响。分类器已经使用夜光/建筑等压力相关变量，所得类均值也不自动代表“未受威胁的内禀H_j”。随后再乘InVEST退化项，可能重复使用同一种城市化信息。

presence-only通常识别相对强度，而非绝对出现概率；有限背景的普通logistic也不自动与MaxEnt完全等价。[Fithian与Hastie原研究](https://arxiv.org/abs/1207.6950)

复核旧数据，背景方案间最小秩相关为0.283；B2下夏/秋/冬相对春的相关约0.900/0.933/0.867。它们均不能独立证明H_j已识别。原剖面全域平均还包含锁定域的环境分布，虽然没读测试鸟类响应，也不能称为纯训练域参数定标。

本轮修正：使用各拟合表自己的特征列、验证栅格CRS/原点，类剖面仅在对应外折fit mask内计算；缺变量或未收敛失败。**尚未重跑72个修正后的真实拟合，因此不产生一套替代旧H_j的正式值。**

## 4. 原观测盘点与调查设计修订

冻结开发出现点跨季物理像元去重后，有451个像元映射到有效LULC。代码1/2/3/4/5/6/7/8/9分别为84/3/42/32/3/39/7/186/55。原交接表的452需区分未映射像元；两者都不是独立访问数量。

示例：类别1有效面积456.37 km²，84个像元对应约**184.06个/千km²**，不是14,047。类别2面积19.19 km²，3个像元对应156.33个/千km²。修正表位于本地 `unique_development_class_coverage.csv`；高低密度不能单独归因生境偏好或面积限制。

采用的调查框架：

1. 先核实类别2/5/7及对照类别的真实地表状态，避免按未经确认的“湿地植物/大型建筑”标签出路线。
2. 按类别×季节×可达性分层选**调查单元和访问**，保存抽样概率/替补规则；不以必须找到30个鸟点为结束条件。
3. 记录完整清单、有效观测时长、人数、距离/面积、天气、水位、可达性、定位精度和真实零水鸟访问；同一单元安排短窗口重复调查。
4. 用先导访问的检测率、空间相关与成本做模拟或功效评估，决定访问量和重复次数。数量及验收阈值在观察正式结果前登记。
5. 响应先定义为可比较的水鸟使用/数量指标；占域模型需重复检测和相应闭合条件。不能把缺清单当缺席。
6. 独立性依据目标定义、来源事件与fit/tune/calibrate用途隔离。同一团队可以采集真正留出的新资料；第三方身份、年份不同也不自动保证独立。新监督仍需底模来源排除审计。
