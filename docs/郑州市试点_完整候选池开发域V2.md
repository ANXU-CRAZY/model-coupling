## 筛选、拟合与评估

- 两个预定方案：排除两层 LST 的 23 变量池，以及包含两层静态参考 LST 的 25 变量池。重复四季的 LST 不解释为四季实测地表温度。
- 每个实际拟合折只使用该折拟合背景去除常量，并按预定字母顺序实施绝对 Spearman 相关阈值 0.7 的贪心筛选。
- 官方 MaxEnt 3.4.4；RM 为 0.5、1、2、4，FC 为 L、LQ、LQH。最大 500 次迭代，单个 Java 进程、384 MB 堆；不依据外折成绩临时提高迭代上限或改变网格。
- 三种背景：B0 目标群、B1 均匀、B2 访问密度代理。访问代理只用拟合域访问位置，不等于已验证调查努力量；背景不作为真实缺失。
- 每季三个外层折、各三个内层折；另有全开发域三个内层折用于冻结后续部署候选。计划 3,456 个内层候选模型及 72 个外层重拟合模型。
- 参数选择沿用 V1：内层遗漏率门槛 0.2、最佳 AUC 的一标准误范围，再按复杂度、绝对训练验证差距、RM/FC及名称确定顺序。外层成绩不用于该选择。
- 折外 M 由内层选出的主要背景成员提供；U_M 为三种背景成员的标准差。成员分位数及标准差不是置信区间。
- AUC 是出现相对于背景的排序统计量；cloglog 作为适宜性评分，不声称已校准出现概率。

沿用父实验的两层选择语义：在全部背景候选中选择主要背景，同时每个背景各自按相同规则选择 RM/FC 并重拟合。因此，“主要背景选择候选”的 RM/FC 不一定等于该背景最终成员的 RM/FC；M 使用实际背景成员，审计分别记录这两种角色。全开发域内层验证选出的后续部署候选另行冻结，本轮没有部署重拟合。遗漏率约束失败时仍保留预定最小遗漏回退标记，不能把回退写成已满足门槛。

## 锁定域与恢复约束

V1 的内部锁定测试已使用。新入口只读取冻结划分 JSON、掩膜和文件哈希，不反序列化划分目录中的鸟记录 CSV；不调用锁定测试声明、不生成锁定域预测、不读取锁定测试指标。折外数组的有限值必须恰好覆盖开发域，锁定域必须为空。本轮也不拟合全域部署模型。

每个完成的内层批次或外层成员生成 `completed.json`，保存实际模型、指标和来源。恢复必须明确使用 `--resume`，同时输入、配置、划分、源码哈希一致且原进程已结束；完成批次按保留输出哈希验证后复用。未完成批次使用新的 attempt 目录重试相同参数，保留失败证据。活动进程锁防止同一路径并发启动。

官方预测坐标、行数、输出尺度和模型哈希通过核查后，保留训练表、背景表、预测 CSV、lambda、官方报告及来源信息；对可重建的 `projection.csv` 和 `projection_inputs/*.csv` 先保存逐文件哈希/字节清单，再删除。删除收据用于解释官方原输出清单中已清理的副本，不伪装为仍存在。

后续采纳已有先导抽样与记录模板，先核实地类、调查范围、完整目标清单和努力量，再评估检出/未检出的生态估计量、独立监督及生境参数准入。实际结果如下。

## 收敛、约束、空间稳定性与保存

- 审计 360 个完成批次、3,456 个内层候选和 72 个外层成员。557 个内层候选达到 500 次上限；72/72 外层成员及 96/96 主要背景选择/后续候选内层模型具有收敛证据。对全部背景的 288 个选定内层模型另查出 1 个达到上限：春 static_lst、outer_2/inner_0、B0、RM0.5/LQ；该背景外层重拟合已收敛。保留此敏感性成员限制，没有事后提高上限或重选。
- 32 次主要背景/后续候选选择中，9 次内层遗漏约束失败，全部位于外层选择；八个全开发域后续候选均通过。96 次背景分别选择中有 40 次约束失败。均按原定最小遗漏回退，不能称全部满足 0.2 门槛。
- 八套 OOF 每套恰好覆盖 560,197 个开发域像元，锁定域预测数全部为 0；M、三个背景成员、标准差 U_M 及分位数已逐值核实。U_M 仅描述成员差异。
- V1/V2 主链 OOF 的秩相关约 0.815—0.988；秋 no_lst 和冬 no_lst 的高分十分位集合 Jaccard 分别约 0.335、0.309。分位数阈值保留并列值，集合不是强制恰好 10%。地图变化不等于独立生态准确率，应纳入先导调查核查。
- 删除 648 个可重建投影输入文件，共 6,117,390,732 字节（5.697 GiB），逐文件路径、字节数和 SHA-256 收据已核实。原始数据、冻结输入/划分、模型、拟合表、预测 CSV 和指标仍保留。
- 完整测试套件 148/148 通过、无跳过，包含官方 Java MaxEnt 合成集成测试；日志为本地 `contracts_full_002.log`。工程测试不构成真实生态验证。
